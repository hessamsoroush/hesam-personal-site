# Hesam Soroush — Personal Portfolio

Static HTML/CSS/JS portfolio designed for GitHub Pages.

## Structure
- `index.html`
- `styles.css`
- `script.js`
- `assets/hesam-profile.png`
- `assets/gallery/digikala-team.png`
- `assets/cv/Hesam-Soroush-CV.pdf` (place your final CV here)

## GitHub Pages
Upload the **contents of this folder** to the root of your repository. Do not put the project inside another nested folder.

The image paths are intentionally relative:
- `assets/hesam-profile.png`
- `assets/gallery/digikala-team.png`

This makes the site work correctly as a GitHub Pages project site.

## Add more photos
Put new photos in `assets/gallery/`, then duplicate one of the `<figure>` cards in the Gallery section of `index.html`.
